Automated Business-Glossary Term Assignment

Tens of thousands of fields had no business terms, and manual tagging was inconsistent. I built an explainable way to assign them, with data stewards kept in the loop.

  • Python
  • scikit-learn (TF-IDF)
  • pandas
  • Excel output

The Problem

A data catalog is only useful if fields are tagged with business terms from the governed glossary. Tens of thousands of fields from legacy and modern platforms had no terms. Manual tagging would have taken months, and different people tagging the same field gave inconsistent answers.

What I Built

A multi-signal scoring pipeline that assigns a business term to each field and attaches a confidence tier:

  1. Semantic grouping: rows are grouped by field name plus normalized description, so the same field with the same meaning always gets the same term.
  2. Evidence collection: bridge mappings from already-tagged systems, direct name matches, and exact token matches against term names.
  3. TF-IDF similarity: compares each field against a corpus built from term names, definitions, domains and example assets.
  4. Scoring: TF-IDF is the primary signal. The other signals can only confirm a candidate, never override it.
  5. Verification and output: consistency checks, phantom-term detection, polysemantic warnings, and a workbook with assignments, a summary and a needs-review sheet.

Why This Approach

Explainable beats opaque here. Data stewards need to see why a term was chosen. TF-IDF with transparent boosts gives a traceable score, and the needs-review sheet sends uncertain cases to people instead of hiding them.

Outcomes

  • Bulk-tagged a large legacy estate in hours instead of months, with high-confidence assignments ready for steward sign-off.
  • Through four iterations, I recorded 11 concrete bugs and their fixes. One example: noisy bridge columns that mapped to 5+ terms had been outvoting real evidence.
  • Packaged as a reusable skill, so the method and its lessons apply to any new platform.

Lessons

Grouping by meaning before scoring was the biggest quality jump. Consistency is a feature stewards notice right away.
