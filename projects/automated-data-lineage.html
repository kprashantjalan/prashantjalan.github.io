Automated Data Lineage from Source Code

Regulators and data owners needed to know where critical data comes from, but the documentation was manual and out of date. I automated the answer by reading the code itself.

  • Python
  • Static analysis
  • Protobuf parsing
  • Config resolution
  • Benchmark harness

The Problem

Regulators and data owners need to know where every critical data element comes from. The existing lineage documentation was maintained by hand, incomplete, and often out of date compared with the code. The platform spans dozens of streaming jobs, event-driven services and REST APIs.

What I Built

A lineage extraction framework that reads the code itself:

  • Topic-level lineage: per-framework extractors (streaming-job configs, Spring listeners, registry files, ingestion YAML) resolve producer → topic → consumer edges. Results are joined into one scored graph, with a provenance tag on every edge.
  • Field-level lineage: for selected systems, traces each target field back through mappers and converters to a real source. A real source is a stream field, a database column, a config row, an inbound API or a file, and never an in-memory object.
  • Benchmark harness: scores precision and recall against a hand-curated “gold” register and classifies every gap by cause.
  • Drift report: a two-sided diff of code versus documentation.

Why This Approach

I measured before deciding. Field-level tracing through a 7-hop streaming pipeline compounds error (95% per hop gives about 70% end to end), so I parked automated field extraction for those jobs and focused on topic-level lineage, where accuracy is high.

Outcomes

  • Topic inventory recall of about 97%. Producer-to-consumer edges reached about 94% recall at about 97% precision in the deliverable tier.
  • The drift report found code-only and documentation-only topics that manual review had missed.
  • The no-fabrication rules were later packaged as reusable skills for AI agents.

Lessons

Benchmark against ground truth early. The scorecard, not intuition, decided where to invest.
