AI and Data Projects

Projects where I used AI and automation to make data analysis faster and more trustworthy. Each one has a full write-up.

Data Lineage and Quality

  • Automated Data Lineage from Source Code

    Regulators and data owners needed to know where critical data comes from, but the documentation was manual and out of date. I automated the answer by reading the code itself.

    94% recall at 97% precision

  • Lineage QA Verification Agent

    One made-up mapping can undermine trust in a whole deliverable. I built an automated review that checks every claim before it reaches stakeholders.

    Every lineage deliverable verified before sign-off

  • Lineage-Driven Data Quality Rule Generation

    Data quality rules were written by hand and often pointed at the wrong tables. I led an AI approach that writes them from plain-English business rules and recorded lineage.

    SQL accuracy up from 82% to 91%, for a few dollars a month

Data Catalog and Governance

  • Data Catalog Explorer

    The governance team answered everyday questions with a dozen scripts and spreadsheets. I gave them one app built around the questions they actually ask.

    Hours of spreadsheet work now take seconds

  • Versioned Data Catalog Warehouse

    Analysts could only query the data catalog one asset at a time, with no history. I turned it into a warehouse they can analyze with plain SQL.

    Millions of records, queryable in seconds

  • Stream-to-Table Mapping Generator

    The catalog needed about 100,000 mappings that no one could build by hand. I generated and verified them, and flagged thousands of existing errors.

    120,000 verified mappings

  • Schema-vs-Catalog Drift Detection

    Nobody knew how far the catalog had drifted from reality. I made the gap measurable and repeatable for the governance team.

    A full drift report in about 7 seconds

  • Business-Glossary Term Assignment

    Tens of thousands of fields had no business terms, and manual tagging was inconsistent. I built an explainable way to assign them, with data stewards kept in the loop.

    Months of manual tagging done in hours

AI Tools I’ve Led

  • Reliable AI-Agent Workspace
